## 📌 Sobre o projeto

Conversor de moedas desenvolvido para praticar JavaScript, captura de valores, formatação monetária e atualização dinâmica da interface. O projeto organiza HTML, CSS, scripts e um fluxo de automação no GitHub.

> **Observação:** Antes de usar o projeto para decisões financeiras, verifique se as taxas utilizadas estão atualizadas. Este repositório tem finalidade educacional.


---

## ✨ Funcionalidades

- Entrada de um valor para conversão.
- Seleção das moedas de origem e destino.
- Cálculo e exibição do valor convertido.
- Formatação monetária na interface.
- Atualização visual conforme as opções selecionadas.

---

## 🛠️ Tecnologias utilizadas

**HTML5**, **CSS3**, **JavaScript**, **GitHub Actions**.

---

## 📂 Estrutura do projeto

- `index.html` — estrutura do conversor
- `style.css` — layout e apresentação visual
- `scripts.js` — lógica principal de conversão
- `scriptbeta.js` — versão alternativa ou experimental do script
- `assets/` — ícones e imagens das moedas
- `.github/workflows/` — configuração de automação do repositório

---

## ▶️ Como executar

1. Clone o repositório: `git clone https://github.com/souza-jp81/Projeto-conversor-de-moedas.git`
2. Acesse a pasta: `cd Projeto-conversor-de-moedas`
3. Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no VS Code.

O projeto não exige instalação de dependências nem configuração de servidor para uso local.
